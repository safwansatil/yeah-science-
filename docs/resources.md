# Resources for this repo

Start with what you need for the next step. These are references, not a reading list you must finish before touching the app.

## Git and the terminal

- [GitHub: contributing to a project](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project) — fork, clone, branch, commit and open a PR.
- [Git Flight Rules](https://github.com/k88hudson/git-flight-rules) — find a situation similar to your Git mishap.
- [Missing Semester: the shell](https://missing.csail.mit.edu/2020/course-shell/) — paths, permissions, pipes and redirection.
- [The Art of Command Line](https://github.com/jlevy/the-art-of-command-line) — Basics and Everyday Use sections.
- [Git from the Bottom Up](https://jwiegley.github.io/git-from-the-bottom-up/) — optional, if you want to understand Git more deeply.

## Understanding the application

- [Qt for Python: getting started](https://doc.qt.io/qtforpython-6/gettingstarted.html) — use this repo's pinned requirements for installation.
- [Your first QtQuick/QML application](https://doc.qt.io/qtforpython-6/tutorials/basictutorial/qml.html) — how Python and QML meet.
- [Qt signals and slots](https://doc.qt.io/qtforpython-6/tutorials/basictutorial/signals_and_slots.html) — how events reach Python methods.
- [QML Keys](https://doc.qt.io/qt-6/qml-qtquick-keys.html) — keyboard events and auto-repeat.
- [QML focus](https://doc.qt.io/qt-6/qtquick-input-focus.html) — who receives a key event.
- [Python unittest](https://docs.python.org/3/library/unittest.html) — write a small regression test; the existing tests use this.
- [Python sockets](https://docs.python.org/3/library/socket.html) — look up the calls used in `link/udp.py`.
- [Missing Semester: debugging and profiling](https://missing.csail.mit.edu/2020/debugging-profiling/) — logs, process inspection and performance investigation.

Further reading: [Grokking Simplicity](https://www.manning.com/books/grokking-simplicity), by Eric Normand. It is optional; no purchase is needed for this task.
